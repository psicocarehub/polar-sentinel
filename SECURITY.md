# Politica de seguranca

## Divulgacao coordenada

O Polar Sentinel trata seguranca como prioridade. Se voce encontrar uma
vulnerabilidade no harness ou um novo vetor de ataque relevante para sistemas de
IA do Judiciario, pedimos divulgacao coordenada.

* Nao abra issue publica para vulnerabilidades.
* Use o aviso privado do GitHub: aba Security deste repositorio, botao
  "Report a vulnerability". Descreva o problema, o impacto e, se possivel, um
  caso de teste anonimizado.
* Respondemos pelo proprio aviso, com um plano de correcao.

Este repositorio reune apenas vetores ja descritos em literatura publica. Um
vetor novo que afete sistemas de tribunais deve ser comunicado primeiro ao orgao
afetado, pelo canal acima, antes de qualquer divulgacao ampla, em linha com a
pratica internacional de coordinated disclosure.

## Escopo

Em escopo: as camadas de referencia, o orquestrador, o pipeline, o corpus e o
gerador de PDFs deste repositorio.

Fora de escopo neste repositorio: o manuseio do certificado ICP-Brasil, o cofre
de chaves e as integracoes especificas de PJe e eproc, que permanecem privados.

## Dados de teste

Todos os exemplos e PDFs de teste usam dados ficticios. Nunca envie dados reais,
sigilosos ou sob segredo de justica em issues ou PRs.
